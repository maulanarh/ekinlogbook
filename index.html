Cara menyambungkan

  1. File Excel Anda saat ini tidak bisa ditulis otomatis. Buka di Drive → File → Simpan sebagai Google Sheets, lalu tempel link hasilnya di atas.
  2. Buka script.google.com → Proyek baru → tempel kode di bawah, ganti KUNCI.
  3. Deploy → Deployment baru → Aplikasi web; jalankan sebagai: Saya; akses: Siapa saja. Izinkan akses, salin URL ke kolom di atas.
